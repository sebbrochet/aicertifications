## The two Copilots

Throughout this book, **Microsoft 365 Copilot** (the productivity assistant across Microsoft 365) is distinct
from **GitHub Copilot** (the developer coding assistant, certified separately as GH-300). This book covers
Microsoft 365 Copilot and the broader Microsoft AI portfolio; it does not cover GitHub Copilot.
